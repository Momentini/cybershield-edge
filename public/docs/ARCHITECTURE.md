## 2. Decisioni sull'Architettura Software (ADR)
- **Framework (Astro):** Scelto per l'Architettura a Isole (zero JS inviato al client di default, massimo punteggio Lighthouse)[cite: 1].
- **Styling (Tailwind CSS):** Utility-first CSS per sviluppo rapido, responsività nativa e coerenza cromatica[cite: 1].
- **Tipizzazione (TypeScript):** Garanzia di qualità del codice e prevenzione errori a runtime[cite: 1].
